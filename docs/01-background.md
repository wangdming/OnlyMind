# 01 · 项目背景

## 一句话

**OnlyMind** —— 让你在手机上给「待命在电脑上的 Claude Code / Codex」下达任务,电脑执行后把结果回传手机,并支持分页查看历史任务。

## 要解决的问题

电脑上的 AI 编码助手(Claude Code、Codex)能力很强,但只能坐在电脑前用。很多时候人不在电脑旁,却想临时发一个任务:

- 「把 ~/projects/foo 的 README 翻译成英文」
- 「跑一下测试,把失败的贴给我」
- 「总结一下今天 git log 改了什么」

OnlyMind 把这件事变成「掏出手机发一条任务」。

## 核心流程

```
手机填写任务 → 提交到电脑上的常驻服务 → 进入串行队列
   → 调用 claude -p / codex exec 执行 → 捕获输出
   → 落库 → 手机轮询拿到结果 / 分页翻历史
```

## 设计约束(来自需求确认)

| 维度 | 决策 | 说明 |
|------|------|------|
| 手机端形态 | **网页(PWA)** | 免安装、免上架,手机浏览器打开即用 |
| 连通与存储 | **本地直连 + 内网穿透** | 不依赖云服务器;数据存在电脑本地 SQLite |
| 任务范围 | **通用任意任务** | 可指定工作目录,执行权限放到最大 |
| 引擎 | **Claude Code 与 Codex 都支持** | 手机端每次提交时选择 |

## 非目标(当前版本不做)

- 不做云端多租户 / 账号体系(单人自用)。
- 不做实时流式输出(先用 2 秒轮询拿最终结果,后续可升级 SSE/WebSocket)。
- 不做多台电脑编排(一个服务对应一台电脑)。

## 关键风险

执行权限放到最大(`--dangerously-skip-permissions`)意味着任何能访问到服务的人都能在你电脑上跑任意命令。因此**远程访问必须用 Cloudflare Tunnel + Cloudflare Access 鉴权 + API 令牌多重保护**(局域网内可直接用 LAN 地址),详见 [02-架构 · 安全](./02-architecture.md#安全security)与 [08-远程访问](./08-remote-access.md)。
